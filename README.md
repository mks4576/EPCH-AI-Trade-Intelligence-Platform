# 🌍 EPCH AI Trade Intelligence Platform

> AI-powered international buyer discovery and trade intelligence platform built with **Python**, **Streamlit**, and **Google Gemini AI**.

---

## 📖 Project Overview

The **EPCH AI Trade Intelligence Platform** is an AI-powered application designed to help exporters discover potential international buyers using Generative AI.

The application demonstrates how Large Language Models (LLMs) can assist export promotion organizations such as the **Export Promotion Council for Handicrafts (EPCH)** by generating buyer recommendations, trade intelligence, and structured business insights.

This project is being developed as a learning portfolio while exploring modern AI application development using free and open technologies.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/mks4576/epch-ai-trade-intelligence-platform.git
```

Navigate to the project

```bash
cd epch-ai-trade-intelligence-platform
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```
GOOGLE_API_KEY=YOUR_API_KEY
```

Run the application

```bash
streamlit run app.py
```
